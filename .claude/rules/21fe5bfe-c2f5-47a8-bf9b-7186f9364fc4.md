### Rules

- **R-ASTRO-001** MUST: Use astro files for all components

### Verify

The source ADR does not include an explicit verify section.

```bash
# Check for component files that are not .astro files in common component directories
find . -path ./node_modules -prune -o -type f \( -name "*.jsx" -o -name "*.tsx" -o -name "*.vue" -o -name "*.svelte" \) -print | grep -iE '(component|comp)' && echo "Found non-Astro component files" || echo "All components use .astro files"
```

**Accept when:**
- All component files use the `.astro` extension
- No React (`.jsx`/`.tsx`), Vue (`.vue`), or Svelte (`.svelte`) files are used for components
